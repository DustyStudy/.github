# Getting help

- **Questions, bugs and feature requests:** open an issue in the repository concerned, using the bug or feature template. Include versions, where it runs and a minimal reproduction, with account IDs and secrets removed.
- **Security vulnerabilities:** report privately. See the [security policy](https://github.com/DustyStudy/.github/blob/main/SECURITY.md).
- **Scope:** these are solo-maintained open-source projects with no SLA.
