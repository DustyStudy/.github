# DustyStudy default community files

GitHub uses the files here for any public DustyStudy repository that does
not have its own copy: the security policy, contributing guide, code of
conduct, support page, and the issue and pull request templates.

A repository overrides a file by adding one of the same name. Issue templates
are all-or-nothing: a repository with its own `.github/ISSUE_TEMPLATE` folder
uses none of the templates here.
