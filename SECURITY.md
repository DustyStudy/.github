# Security Policy

## Reporting a vulnerability

Please report a vulnerability privately rather than opening a public issue:
in the affected repository, go to **Security -> Report a vulnerability**.
Private vulnerability reporting is enabled on every public DustyStudy
repository.

These are solo-maintained projects with no SLA, so reports are handled as
time allows.

Worth reporting: a secret or credential exposed in code, logs or output;
IAM, SCP or Terraform that grants broader access than documented; a way to
bypass a guardrail or check the project claims to enforce; or a weakness in
a CI workflow or release artifact.

## Supported versions

Only the latest release of each project (or `main`, where there are no
releases) receives fixes.
